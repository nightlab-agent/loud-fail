# Catalog

| Path | Read it when |
|---|---|
| `loud_fail.py` | You change fixtures, argv, timeouts, signals or the table. |
| `loud_fail_core.py` | You change a case or how a run is classified. |
| `INTERFACE.md` | You need the contract between the runner and the core. |
| `CHECKS.md` | You need the evidence behind a claim in the README, or the real-tool trial commands. |
| `test_*.py` | You change behaviour: add a case first. |
| `tests/release.sh` | You release. |
| `01-context/purpose.md` | You judge whether a change fits. |
| `04-memory/STATE.md` | You need what is true now. |
| `examples/` | `quiet_reader.py` (the README example) and `trials/`: `run-trials.sh` and its five per-tool logs behind CHECKS.md. |
